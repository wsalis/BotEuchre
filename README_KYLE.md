# Kyle Model Notes

Kyle is the aggressive neural specialist derived from the balanced Arbiter lineage.
In this public release, it is distributed as a frozen gameplay/evaluation checkpoint.

## Checkpoint

- File: `kyle_weights.pth`
- SHA-256: `0bbf53e0290f15d0eda769d3419dcd4f9d06cfea8357ef88fa3594dd41844e86`

## Style Intent

Kyle is tuned to pressure scoring chances with thinner partnered calls and more
proactive aggression than Arbiter.

## Provenance

This checkpoint originated from a separate internal training branch that is not
included in this repository. Only the final checkpoint required for gameplay and
evaluation is distributed here.
