# Ironclad Model Notes

Ironclad is the conservative neural specialist derived from the balanced Arbiter
lineage. In this public release, it is distributed as a frozen gameplay/evaluation
checkpoint.

## Checkpoint

- File: `ironclad_final_gen18.pth`
- SHA-256: `53e6098ad4d1bcfcb4d96100ac296f34c52f0ba3a630ac7f27e0fe1bd74ebd21`

## Style Intent

Ironclad is tuned to be more selective and risk-aware than Arbiter, with stronger
emphasis on disciplined calls and reducing unnecessary euchre exposure.

## Provenance

This checkpoint originated from a separate internal training branch that is not
included in this repository. Only the final frozen checkpoint required for gameplay
and evaluation is distributed here.
